# GPU 렌더러 (계획)

아직 만들지 않았습니다. 이 문서는 로드맵 4번 항목의 계획입니다. 3D 장면을 GPU로, 휴대폰의 해상도에
맞춰, 안티에일리어싱과 함께, Vulkan으로 그리는 일입니다.

## 지금 있는 것

디컴프 런타임은 모든 것을 DS 크기로 직접 그립니다. `gpu3d.c`(기하 엔진과 래스터라이저, 256×192)와
`gpu2d.c`(2D 엔진. 3D 그림을 레이어 하나로 받아 다른 레이어와 줄 단위로 섞음)가 그것입니다. 화면 코드는
완성된 그림을 확대합니다. 확대로는 디테일이 늘지 않습니다. 선명한 3D를 얻으려면 삼각형을 큰 크기로
다시 그려야 합니다.

## 필요한 것

1. **엔진에서 장면 꺼내기.** 기하 엔진이 한 프레임의 폴리곤을 변환·클리핑·정렬하면 목록(`gpu3d.c`의
   `PolygonList`)에 담깁니다. 화면 좌표와 깊이·w, 색, 텍스처 좌표, 폴리곤별 속성·텍스처 파라미터·팔레트가
   들어 있습니다. 어떤 렌더러든 이 목록과 텍스처 메모리에서 시작합니다. 포트는 이미 `gpu3d.c`를 자기
   파일(`port/src/gpu3d_main.c`, `gpu3d_upper.c`)을 통해 빌드하므로, 디컴프를 고치지 않고 목록을 꺼낼 수
   있습니다. 이어진 화면의 위·아래 절반도 각각 이런 목록입니다.
2. **DS의 픽셀 규칙을 셰이더로.** 텍스처 형식 7가지(자체 알파를 가진 것 둘, 4×4 블록 압축 하나), 모듈레이트,
   데칼, 툰·하이라이트 셰이딩, 그림자 폴리곤, 알파 테스트와 폴리곤 ID 규칙을 따르는 블렌딩, 안개, 외곽선,
   z 또는 w 깊이. 각각 소프트웨어 래스터라이저와 같은 결과를 내야 하며, 소프트웨어 쪽이 기준으로 남습니다.
   한 프레임을 두 방식으로 그려 비교할 수 있습니다.
3. **그 위·아래의 2D 레이어.** 게임의 2D 레이어는 프레임마다 정해지는 규칙(우선순위, 윈도, 알파, 밝기)으로
   3D 그림과 DS 크기에서 섞입니다. 3D 그림을 크게 그리려면 2D 엔진의 일을 "3D 레이어 아래에 깔리는 것"과
   "그 위에 놓이는 것, 그리고 둘이 섞이는 방식"으로 나눠서, 섞기를 큰 크기에서 할 수 있어야 합니다. 계획은
   2D 엔진에 각 줄을 세 번(3D 레이어가 전부 검정, 전부 흰색, 없음) 물어보는 것입니다. 세 답에서 임의의 3D
   색에 대한 혼합식이 나오며, `gpu2d.c`는 고치지 않습니다.
4. **Vulkan.** SDL이 주는 창에 스왑체인을 만들고, 장면을 창 크기의 멀티샘플 타깃에 그린 뒤 2D 혼합과 터치
   버튼을 얹습니다. Vulkan이 없는 기기를 위해 OpenGL ES 경로를 남깁니다. 안티에일리어싱은 타깃의
   멀티샘플링이고, 해상도는 창을 따릅니다.

## 순서

1. 장면을 꺼내고, 포트 안에 DS 크기의 정수배로 그리는 두 번째 소프트웨어 래스터라이저를 만들어 1배에서
   디컴프의 것과 대조합니다. 꺼내기가 맞는지 증명되고, 셰이더의 기준이 됩니다.
2. 2D 레이어의 세 답 혼합을 같은 방식으로 1배에서 대조합니다.
3. Vulkan 렌더러를 기능 하나씩 그 기준과 대조하며 만듭니다. 여기서는 소프트웨어 Vulkan 드라이버로, 그다음
   휴대폰에서 확인합니다.
4. 설정: 해상도(기본은 자동), 안티에일리어싱, 그리고 소프트웨어 렌더러를 선택지로 남깁니다.

## 바뀌지 않는 것

게임 자체의 프레임. 디컴프의 소프트웨어 렌더러는 계속 프레임 검증이 비교하는 그림을 만들고, 화면에
보이는 것은 GPU의 그림입니다.
